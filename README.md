# P 寶可夢 雷光RUSH

仿近代日本デジパチ（數位柏青哥）的網頁遊戲：Canvas 棋盤物理、中央液晶 3 轉輪，SP／SPSP リーチ、全回轉、保留變化、擬似連、ステップアップ等演出影片用 MiniMax H3 生成（RunningHub，0.4 MP）。UI 字卡與 logo 用 GPT 生成。獎勵是鋼珠（持ち玉），沒有圖鑑。

- 玩法：按「發射」，拉桿調力道；通常時左打ち進 START，大当り／RUSH 中右打ち。SP／SPSP 高潮按 PUSH。
- 洞口：
  | 洞口 | 位置 | 進去會怎樣 | 何時瞄準 |
  |---|---|---|---|
  | START（ヘソ） | 液晶正下方金框 | +3 顆，抽一次大獎；轉輪在轉時存成保留（最多 4 個） | 通常時，左打ち |
  | GATE | 右側通道上方弧形 | 不給珠，讓電チュー打開 | 右打ち一定經過 |
  | 電チュー | 右側通道中段紅翅膀 | +1 顆，也抽大獎；RUSH 中每次過 GATE 開約 2 秒 | RUSH 中，右打ち |
  | ATTACKER（大獎口） | 右下金色斜板 | 大当り時才開，每顆 +15，每回合 10 顆或 25 秒，10R 約 1,500 顆 | 大当り中，右打ち |
  | 紫框小洞（一般入賞口） | 左下、中下 | +5 顆，不抽獎 | 隨緣 |
  | OUT | 最下面黑色橢圓 | 沒進洞的珠子回收 | — |
