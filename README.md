# P 寶可夢 雷光RUSH

仿近代日本デジパチ（數位柏青哥）的網頁遊戲：Canvas 棋盤物理、中央液晶 3 轉輪，SP／SPSP リーチ、全回轉、保留變化、擬似連、ステップアップ等演出影片用 MiniMax H3 生成（RunningHub，0.4 MP）。UI 字卡與 logo 用 GPT 生成。獎勵是鋼珠（持ち玉），沒有圖鑑。

- 玩法：按「發射」開始打珠。通常時按「左打ち」進 START 抽獎；大当り／RUSH 中按「右打ち」（預設自動切換）。SP／SPSP 高潮按 PUSH。珠打完按機台上的「借玉」。
- 圖柄是 9 隻寶可夢：聽在哪個數字就由那隻出場，中獎時 1–5 打贏對手、6–9 用寶貝球收服。奇數＝10R＋RUSH，偶數＝3R。
- 桌機三欄：左邊統計（收支、鋼珠增減圖、ハマリ、實測機率、大当り履歴），右邊演出信賴度（理論 vs 你的）、成就、說明、設定。手機版用上方 📊 和 ☰ 打開。
- 演出與機率：見 [演出設計.md](演出設計.md)
- 網址參數：`?reset` 清存檔、`?fast` 測試用（大当り回合瞬間打完）
